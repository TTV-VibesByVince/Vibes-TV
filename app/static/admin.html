Stream overlay

The same alerts on your stream, as small see-through cards in a corner. No logo, no background: it's empty between alerts. It has its own queue, so it never waits for a TV clip.

  • In OBS, add a Browser source with this address, Width 1920 and Height 1080. No custom CSS needed: the page is already transparent.
  • Turn Shutdown source when not visible off, so it stays connected when you switch scenes.
  • Want the alert sounds on stream? Tick Control audio via OBS. Clips are off on the overlay by default so their sound doesn't play twice.

Where each alert plays, and how big it is on stream

Compact: a small card in your corner. Centre: a bigger card in the middle, the stream a little darker. Full screen: the TV's own animation over your game, the stream darkened behind it (a web page can't blur what's under it in OBS). "Each alert (seconds)" is for Compact and Centre; Full screen uses the TV's timings. A URL's &screen=tv, overlay or both overrides where one alert plays. Room lights always follow the TV.

TikTok LIVE Off

Optional. Shows follows, subscriptions and gifts from your own TikTok LIVE, with the same cards, queues and routing. It uses TikTokLive, an unofficial open source library that reads the same live feed the TikTok app shows. TikTok doesn't support it, so it can stop working for a while when TikTok changes things.

Text to speech Off

Reads TikTok LIVE chat aloud (and anything MixItUp sends to /tts), one message at a time, in a Microsoft Edge voice. It plays on the stream overlay by default (in OBS, tick Control audio via OBS on the Browser Source). Uses edge-tts: free and no key, but unofficial, so Microsoft could change it.

Always skipped: commands (!…) and messages with links. When chat is busy, only the newest few wait their turn.

Lights

Vibe TV calls these when a card starts and ends. {hex} becomes the colour picked from the raider's avatar. For Govee Lights Controller (V1.3+), turn on Settings > Accept requests from my network on the PC, then use its address, e.g. http://<pc-ip>:8765/color/{hex}.

Theme

Changes the confetti, the floating shapes on the follow screen (hearts, bats, snowflakes, clovers), the raid's warp colours and the theme colour. Clicking a theme switches every TV right away.

Schedule

Between these dates (every year) the scheduled theme is used instead. The first matching row wins; outside them, the theme picked above.

Text & colours

Change the words on each screen. Leave a box empty to use the default (shown in grey). {name}, {months}, {amount} and the like are filled in; text in [square brackets] only shows when its {placeholder} has a value, e.g. [Last seen playing {game}]. The colour is used for the screen's glow and accent, and for your lights.

Backup

All your settings in one file: timings, text, colours, theme and schedule, light URLs and Twitch keys. Logo files aren't included; they're in the media folder.

Last requests received

The last event URLs that reached Vibe TV, newest first, exactly as they arrived. Use it to check MixItUp filled in its variables: an empty tier= or a leftover $variable means that identifier didn't exist for that event.
